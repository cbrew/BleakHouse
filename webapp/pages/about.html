Pipeline Overview

How a novel becomes a podcast in four phases

Passages flow through enrichment dimensions and expert demand nodes to episode segments. Every arc is inspectable and adjustable.

Phase 0: Enrichment

Each novel is parsed into passages of 50–80 words. Every passage is annotated by Claude Haiku with a 20-field schema:

  • Interest score (0–5): how remarkable is this passage?
  • Seven provision dimensions: character_development, plot_advancement, thematic_depth, social_critique, humor_entertainment, atmosphere_setting, narrative_technique — each rated none/weak/strong
  • Characters present and characters speaking
  • Narrator identification (Esther or omniscient, for dual-narration novels)
  • Themes, emotional register, plot function
  • Quotability and best extractable quote
  • Summary

Corpus: 15 novels, 60,774 passages, 7 authors (1850–1924).

Phase 0.5: Segment Design

Claude Haiku designs 5–8 episode segments based on the expert panel's demand profiles and character arcs. Each segment has a title, type (opening, deep_dive, close_reading, closing), target dimensions, and passage budget.

Phase 1–2: Passage Selection

Three conditions:

Synoptic (Transport)

Min-cost network flow. Each expert has a demand profile over provision dimensions. The solver finds the minimum-cost assignment of passages to experts. Selects ~59 passages from ~28 chapters. Zero LLM tokens, <100ms.

Analytical (Embedding)

Contextual embeddings retrieve candidates by semantic similarity to each expert's profile, then Claude Sonnet curates the final set. Selects ~32 passages from ~20 chapters. ~15K tokens, ~10 seconds.

No Passages

The LLM generates from prior knowledge alone. No Phase 1–2. Used to measure what the model "knows" about each novel.

Phase 2.5: Host Preparation (optional)

Two sub-phases:

  1. Pre-interviews (Haiku): Each expert is interviewed about each segment's passages — key points, desired quotes, disagreement angles. 3 experts × 7 segments = 21 interviews.
  2. Question planning (Sonnet): For each segment, synthesise all interviews into 3–5 targeted host questions with steering notes and cross-engagement targets.

Effect: raises questions per segment from ~1 to ~11, uniformly across all 15 novels.

Phase 3: Script Generation

One Claude Sonnet call per segment produces a structured podcast script with:

  • Speaker turns (Host + 3 experts)
  • Individual utterances with sentence types, quote modes, prosodic annotations
  • Speaking rate, pause timing, emphasis words per utterance
  • Passage references linking each quote to its source

~100K tokens per episode.

Phase 4: Post-Generation

  • report.txt — plain text script
  • manifest.json — passage backlinks, quote matching, host prep data
  • report.html — self-contained dark-themed report with expandable passage reveals
  • Audio rendering (optional) — Gemini TTS with per-speaker voice assignment and accent direction
