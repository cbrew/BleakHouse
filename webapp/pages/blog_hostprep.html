Host Preparation: From Monologue to Dialogue

How pre-interviews and question planning transform generated discussions

Part 4 of the Not In Our Time series

Without host preparation, the system produces expert monologues. Each panelist delivers a mini-lecture about the passages assigned to their segment. The host asks approximately one question per segment. The experts rarely respond to each other.

With host preparation, the mean rises to ~11 questions per segment. Experts build on each other's points, push back, and reference each other's pre-interview claims. The discussions sound like conversations.

The effect is uniform across all 15 novels. This is the key finding: the transformation from monologue to dialogue is architectural, not content-dependent.

Phase 2.5a: Pre-interviews

For each expert×segment pair, Claude Haiku conducts a short interview. With 3 experts and 7 segments, that's 21 Haiku calls per run. The interview prompt asks four questions:

  1. What strikes this expert most about the passages?
  2. Which passage would they most want to quote aloud, and why?
  3. Where might they disagree with the other experts?
  4. What is their single most provocative claim?

The output is a structured PreInterviewResponse: key points, potential quotes, disagreement angles, and a strongest take. These are now saved to phase2_5_interviews.json and visible in every hostprep report.

A concrete example — Elena Volkov's pre-interview for the opening segment of the interdisciplinary panel:

Strongest take: Bleak House is a novel about how beauty, narrative elegance, and formal complexity can become instruments of institutional power — they seduce us into accepting the unacceptable.

Disagreement: Rebecca may emphasise social realism, but I want to push on how he exposes it: through aestheticisation that can actually reconcile readers to the very horrors he's depicting. The fog is gorgeous. That's the problem.

Phase 2.5b: Question planning

For each segment, Claude Sonnet reads all three experts' pre-interviews and plans 3–5 targeted questions. The planning prompt asks for questions that:

  • Draw out each expert's strongest take
  • Set up productive disagreements
  • Create cross-engagement moments
  • Target specific passages for quotation
  • Keep the energy "pub with smart friends, not conference panel"

The output is a HostBrief per segment: questions (with target expert, intent, and follow-up suggestions), steering notes, and cross-engagement targets.

Example steering note:

This segment should feel like three people who've each found a completely different novel inside the same book. Let Rebecca's astrophysics frame land first — it's the most unexpected and will make the audience lean in. Elena should come in third because her political thesis works best when there's already something to push against.

The retry story

During the 180-run matrix generation, one run (Hard Times, no-passages, hostprep) failed because a transient Anthropic API 500 error killed a pre-interview call. The run_pre_interview function had no retry logic — unlike generate_podcast, which retries 3 times.

We added the same 3-attempt retry pattern. This is the kind of robustness issue that only surfaces at scale: 21 Haiku calls per run × 90 hostprep runs = 1,890 pre-interview calls. A 0.1% API error rate hits you twice.
