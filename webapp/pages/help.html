What Can I Do Here?

A guide to exploring the experiment

Experiment Matrix

The matrix shows 180 podcast runs: 15 novels × 2 expert panels × 3 pipelines × 2 host-preparation settings. Each cell displays three numbers:

  • Top (bold): questions per segment — how conversational the host is
  • Middle: reactive markers per segment — cross-expert engagement
  • Bottom (grey): total word count (thousands)

Click any cell to see a popover with phase timings, quote verification stats, and links to the full report and (where available) audio.

Cell colours: green = strong dialogue (Q/seg ≥ 5), yellow = moderate, red = monologue-like, blue = in progress.

Audio Player

The player lets you listen to rendered podcast episodes. Use the dropdowns to select a novel and a run. Runs are labelled with:

  • Expert names (e.g. "Hartley, Blackstone, Woodcourt")
  • Pipeline condition in brackets: [transport], [no passages], [interdisciplinary]
  • +hostprep if host preparation (pre-interviews + question planning) was used

The transcript appears below the player, synchronised with audio playback. Click any passage reference to expand a reveal showing the source passage, summary, and enrichment metadata.

Reports

Every run has a self-contained report page (accessible from the matrix or via /report/{run_id}). Reports include:

  • Passage reveals — click the monospace passage references (e.g. Chapter 11, c11:p62) to expand and see the source passage text, summary, and character/theme/emotion chips
  • Host preparation — for +hostprep runs, expand the "Host preparation" section at the top of each segment to see pre-interviews (each expert's key points, desired quotes, disagreement angles) and the planned host questions with intent annotations
  • Match badges — for no-passages runs, each quote has a coloured badge indicating verification status: Verified Paraphrase Distant echo No source Invented

Other Pages

  • Pipeline — how the system works, from enrichment to audio
  • Prompts — the actual LLM prompts used at each phase
  • Metrics — aggregate statistics computed live from the experiment data
  • Examples — side-by-side excerpts, pastiche analysis, host prep drill-down
  • Research — key findings with charts and data tables
  • Blog — narrative account of the project
