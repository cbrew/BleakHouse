How to use this player

Click any paragraph in the transcript to jump to that point in the audio. The current turn is highlighted as playback progresses.

Try clicking a quoted passage — you'll hear the expert read it aloud with the pacing and emphasis marked in the script.

Passage reveals: click the monospace passage references (e.g. c11:p62) to expand and see the source passage, summary, and enrichment metadata.

Runs labelled +hostprep have richer dialogue — the host asks targeted questions based on pre-interviews with each expert. Compare a hostprep run with its non-hostprep counterpart to hear the difference.

Speed: click the speed button (1x) to cycle through playback rates.
